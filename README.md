# Анкеты VAYGO

Отдельное приложение для Android: электронные анкеты (продуктовый магазин, отель).
Заполняете на телефоне, сохраняете, получаете PDF, отправляете по почте и мессенджерам или печатаете.
Новые типы анкет добавляются как данные в `app/lib/forms/templates.dart`.

Оформление взято из `somon101/app-starter` (тёмная тема Midnight, светлая, белый акцент).
Данные хранятся только на телефоне.

## Сборка APK
1. **Один раз:** создать постоянный ключ подписи. В Settings → Secrets добавить секрет `KEYS_TOKEN`
   (fine-grained токен этого репозитория, Secrets: Read and write), затем Actions → *Create signing key* → Run workflow.
   Без постоянного ключа новая версия не встанет поверх старой, и анкеты на телефоне пропадут.
2. Actions → *Android APK* → Run workflow. Готовый APK появляется в Releases (версия `android-latest`).
3. Ставить на телефон поверх старой версии, удалять приложение не нужно.

Каждый push в `main` запускает проверки: анализ кода и тесты.
